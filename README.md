# Africa delivery demand forecast

Hourly demand forecasting case study for a delivery marketplace in Casablanca, Nairobi and Lagos.

**Data note:** semi-synthetic. Weather and calendar inputs are real; order and courier volumes are simulated from documented assumptions (`docs/assumptions.md`). This is not company data.

Models compared in one walk-forward backtest: seasonal-naive baseline, LightGBM, TimesFM 2.5 (zero-shot).
